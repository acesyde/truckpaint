## REMOVED Requirements

### Requirement: Marketplace tab
**Reason**: TruckPaint stops sharing game-derived packages; players build them from their own game.
**Migration**: None (the app is not released). Install a `.tpv` by hand in the Vehicle Library.

### Requirement: Install from the catalog
**Reason**: There is no catalog to install from.
**Migration**: None.

### Requirement: Cache and offline
**Reason**: There is no catalog to cache.
**Migration**: None.

### Requirement: Privacy and responsiveness
**Reason**: The app makes no network request, so nothing is sent.
**Migration**: None.

### Requirement: Legal notice
**Reason**: The notice belonged to the Marketplace tab; nothing is shared any more.
**Migration**: None. Generated packages keep their own license.
